# Client Kickoff System (Free)

**Inquiry to first kickoff in 24 hours.**

A free, complete client onboarding system for solo freelancers. Turn new inquiries into scheduled kickoffs with intake forms, scope templates, welcome packets, payment checklists, and AI prompts—so you stop reinventing onboarding every time.

## What This Is

Client Kickoff System is a battle-tested framework you can run in Notion, Google Docs, or any notes app. It includes:

- **Client Pipeline Database** — Track every inquiry from first message to project completion
- **7 Copy-Paste Templates** — Welcome packets, intake forms, scope documents, kickoff agendas, revision trackers, invoice checklists, and handoff pages
- **8 AI Prompts** — Generate professional client communications in seconds (inquiry replies, scope confirmations, scheduling, soft pushback for scope creep, and more)
- **Sample Client** — See the system filled out before you customize it
- **20-Minute Setup** — From download to first use in one focused session

**Outcome:** Inquiry → first kickoff call within 24 hours (when the client responds promptly).

## Features

### Client Pipeline Management

Track every client from inquiry to completion with a simple status-based workflow:

```
Inquiry → Qualified → Intake Received → Scope Sent → 
Payment Pending → Kickoff Scheduled → Active → Completed
```

Includes fields for:
- Contact details and communication channel
- Service type and priority
- Next actions with due dates
- Deposit tracking and payment status
- Project notes and client page links

### Professional Templates (Real Copy)

All templates include production-ready language you can customize:

1. **Welcome Packet** — Set expectations and establish trust
2. **Client Intake** — 27 questions that surface scope before you write it
3. **Scope of Work** — Deliverables, timeline, investment, revision policy
4. **Kickoff Call Agenda** — 30-45 minute structured alignment call
5. **Revision Tracker** — Log rounds and enforce boundaries
6. **Invoice & Payment Checklist** — Pre-send verification and follow-up
7. **Project Handoff** — Clean close-out and testimonial request

### AI Prompt Engine

8 copy-paste prompts for ChatGPT, Claude, or similar tools:

1. **Inquiry Reply** — Fast, warm first response
2. **Welcome Email** — Drive intake completion
3. **Info Request** — Chase missing details politely
4. **Scope Confirmation** — Turn intake into client-facing proposal
5. **Kickoff Scheduling** — Book the call fast
6. **Not-a-Fit Decline** — Protect reputation when saying no
7. **First-Week Check-in** — Reduce anxiety, catch blockers
8. **Scope Creep Pushback** — Friendly boundaries without damage

Each prompt includes worked examples and customization variables.

## The 24-Hour Kickoff Path

| Time | Action | Status | Tools Used |
|------|--------|--------|------------|
| **Hour 0** | Inquiry arrives → reply sent | Inquiry | Pipeline + Prompt 1 |
| **Hour 1-2** | Client engaged → intake sent | Qualified | Prompts 2-3 + Intake form |
| **Hour 4-6** | Intake returned → scope drafted | Intake Received | Scope template + Prompt 4 |
| **Hour 6-8** | Scope approved → invoice sent | Scope Sent → Payment Pending | Invoice checklist |
| **Hour 8-12** | Payment received → call scheduled | Kickoff Scheduled | Prompt 5 + Kickoff agenda |
| **Hour 12-24** | Kickoff call held or firmly booked | Active | — |

*Timeline assumes responsive client. Your side should never be the bottleneck.*
